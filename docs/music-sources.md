# 音源使用

QQ 音乐插件在独立仓库 [MeiloX-QQMusic-Source](https://github.com/NEORUAA/MeiloX-QQMusic-Source) 维护。单曲搜索、歌曲详情和歌词可匿名访问；
完整搜索、个人媒体库和播放需要本人 QQ 音乐网页会话。可在音源详情中点击「网页登录」，完成官方登录后点击「完成」，由宿主提取并加密保存会话；也可手动填写网页 Cookie。播放音质按账号授权提供。
凭据保存在音源自己的加密存储中，不需要发到聊天或问题报告里。

网易云音乐插件在独立仓库 [MeiloX-Netease-Source](https://github.com/NEORUAA/MeiloX-Netease-Source) 维护，首次使用时默认安装，升级时保留已有账号。登录、歌单、FM、云盘、播客、消息和一起听仍使用原来的入口。可以在音源管理中禁用或移除，移除后不会自动重装。

## 导入与配置

打开「设置 → 通用 → 音源管理 → 从文件导入」，选择 `.meisource` 文件，核对插件名称、作者、版本和网络权限后安装。点开已安装音源可填写配置、启用或禁用、从文件更新，也可移除。移除音源会保留歌单项和已下载的音频。

声明网页登录能力的音源会显示「网页登录」入口。登录页面和允许提取的 Cookie 由该音源声明，宿主只提取当前独立网页会话内、指定域名与名称的 Cookie。登录状态按音源隔离。关闭页面会保留该音源的网页登录会话，显式退出登录才会由音源清除凭据。

脚本使用应用内置的 QuickJS 引擎，在独立隔离进程运行，不依赖系统 WebView 版本。引擎随应用更新，网络请求、账号存储和缓存由宿主负责。

仓库提供 [离线示例](../samples/music-source-plugin/offline-mock.meisource)，搜索 `Mock Recording` 可播放一秒测试音。这个示例用于验证插件接口，不提供 QQ 音乐或酷狗的实际在线服务。

## 插件市场与更新

打开「音源管理 → 插件市场」可查看和安装音源。市场由独立的 [MeiloX Source Registry](https://github.com/NEORUAA/MeiloX-Source-Registry) 仓库维护，开发者可以提交 PR 上架或更新版本。

启用「启动时自动更新」后，应用启动时在后台检查并更新已安装插件，也可点击音源管理右上角的检查更新按钮。更新保留账号配置和启用状态，不会装回已移除的插件。

新增权限的版本需要重新确认，精确域名改为通配域名也需要重新确认。`*.music.126.net` 表示该域名下的子域，不包含根域名；旧宿主无法识别这种声明，需要先更新应用。自行导入的插件只有在内容与市场登记的同版本包完全一致，或经过一次手动确认更新后，才会跟随该仓库自动更新。下载或校验失败时继续保留已安装版本。

## 浏览与搜索

在音源管理中分别选择默认浏览源和默认搜索源。首页、发现和媒体库跟随当前浏览源，搜索可以单独选择来源。点右上角音源按钮打开菜单切换，搜索结果标明来源。专辑、歌手和歌单始终打开所属音源的详情。

媒体库按当前音源显示喜欢的歌曲、创建与收藏的歌单、收藏的专辑和关注的歌手，并沿用「媒体库样式」设置。账号入口也跟随当前音源，每个插件的登录配置独立保存。下载和本地音乐继续使用宿主入口。

收藏、歌单编辑和排序按音源能力提供；未声明的操作不会出现。消息、听歌识曲、一起听等入口由支持相应功能的音源提供，使用原有界面和交互。

歌词来源独立于内容音源。切换、禁用或移除网易云、QQ 等音源，不会改变歌词来源选择、QQ 手动匹配、逐字歌词、TTML、音译、偏移和缓存。

## 自动切换播放音源

1. 启用并配置可播放的音源。
2. 打开「自动切换播放音源」。
3. 拖动音源右侧的排序柄调整切换顺序，松手后自动保存。
4. 保持「优先原始音源」开启时，会先完成原音源的质量降级和资源刷新，再尝试其他音源。

歌单和喜欢歌曲队列会按需加载后续页，重启后先恢复已加载歌曲，再核对来源、账号和歌单顺序续播。

切换只影响音频资源。原歌单、歌曲资料、收藏及评论目标保持原来的来源。在歌曲信息中可查看实际播放音源和实际音质，也可关闭某首歌的自动切换。

多个候选过于接近时不会自动选择。在音源管理的「确认歌曲匹配」中选择后，下一次播放解析会使用保存的匹配。最近的解析结果也显示在这里。

设置修改从下一次解析请求开始生效，正在播放的歌曲不会突然重启。所有来源都失败时，播放器执行现有的失败提示或跳过策略。

## 数据升级

旧版数据库通过增量迁移加入来源字段，原歌曲、歌单、收藏、播放历史、下载记录和离线路径继续保留。旧队列快照可继续恢复。已有网易云缓存保留兼容读取，新缓存按实际音源、音源实例、歌曲和音质区分。

插件开发见 [Source plugin API](source-plugin-spec.md)，架构及迁移说明见 [Music sources](multi-source-architecture.md)。
